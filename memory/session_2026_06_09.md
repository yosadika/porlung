## R-X Locus Geometry Guardrail

- Trajectory dihitung oleh `build_simple_rx_locus_trajectory()` dari fasor sliding DFT, memakai `calculate_locus_loop_impedance()`.
- Loop ground:
  - `AG`: `Va / (Ia + K0*I0)`
  - `BG`: `Vb / (Ib + K0*I0)`
  - `CG`: `Vc / (Ic + K0*I0)`
- Loop phase:
  - `AB`: `(Va - Vb) / (Ia - Ib)`
  - `BC`: `(Vb - Vc) / (Ib - Ic)`
  - `CA`: `(Vc - Va) / (Ic - Ia)`
- Fault inception dipakai untuk sync/trigger. DFT cursor dipakai untuk titik phasor/locus.
- Zona proteksi memakai `X reach` dan `R reach`:
  - Ground loop memakai kolom `R*G`.
  - Phase loop memakai kolom `R*P`.
- Jangan klaim overlay sebagai replica vendor penuh sampai ada model:
  - tilt reactance,
  - directional supervision,
  - left/right blinder presisi,
  - load encroachment,
  - memory/polarizing quantity,
  - logic blocking / pabrikan.

## Struktur `line_data`

- `line_data` untuk R-X Locus dipisah dari `line_impedance` untuk Line Parameter.
- Credentials:
  - `database_line_sheet = "line_impedance"` untuk Line Parameter.
  - `rx_locus_line_data_sheet = "line_data"` untuk zona R-X Locus.
- Session/config:
  - `line_data_sheet_name`: sheet Line Parameter.
  - `rx_locus_line_data_sheet_name`: sheet zona R-X Locus.
- Struktur aktif `line_data`:
  - `No`, `UPT`, `Tegangan`, `ULTG`, `GI`, `Nama Line`, `Nomor Line`, `SEGMENT`, `Panjang (km)`, `Jenis Konduktor`, `Jumlah Sirkit`, `MERK`, `Type`.
  - Rasio: `VT Ratio primary`, `VT Ratio Secondary`, `CT Ratio Primary`, `CT Ratio Secondary`.
  - Secondary: `Z1/Z2/Z3 Sec`, `R1/R2/R3 P Sec`, `R1/R2/R3 G Sec`, `tZ*`.
  - Primary: `Z1/Z2/Z3 Prim`, `R1/R2/R3 P Prim`, `R1/R2/R3 G Prim`, `tZ*`.
  - Metadata: `Line Impedance`, `VTR/CTR`, `Z Line Prim`, `R Load Prim`, `Real/ABS`.
- Parser R-X:
  - `GI` -> substation.
  - `Nama Line` -> Bay/nama line relay.
  - `Nomor Line` -> nomor line.
  - `Nama Line dan Nomor Line` tetap fallback format lama.
- Guardrail: rasio VT/CT di `line_data` hanya fallback seed Signal Assignment saat CFG berisi `1/1` atau ratio tidak valid. CFG ratio yang valid tetap prioritas; konversi secondary -> primary tetap memakai Signal Assignment aktif agar konsisten dengan waveform.
- Summary menampilkan catatan kaki relay Local/Remote dari `MERK` dan `Type` pada baris `line_data` yang cocok dengan filter sidebar GI/Bay/Line masing-masing end.
