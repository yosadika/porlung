# Session 2026-06-10

## PANEN RISOL evidence untuk estimasi penyebab

- `summary_helpers.py` menambahkan `_panen_risol_evidence_hint()` sebagai rule evidence heuristik terinspirasi workbook `PANEN RISOL (Responses).xlsx`.
- Fitur yang dipakai: `R`, `X`, `R/X`, `X/R`, rasio `3I0/loop`, rasio `3V0/loop`, dan beda sudut loop dari fasor/hasil SE.
- Evidence PANEN RISOL menambah skor kandidat secara konservatif:
  - `Resistif-Pohon` / `Tegakan Non-Pohon` -> `Vegetasi / Pohon`.
  - `Hewan` -> `Satwa Liar (Bird Streamer)`.
  - `Petir` -> `Sambaran Petir / Flashover`.
  - `Flying Object` -> kandidat baru `Benda Asing / Flying Object`.
- Jika fitur tidak masuk window spesifik tetapi `R` dominan atau `X` dominan, Summary memberi bonus lemah: `R` dominan -> Vegetasi/Pohon, `X` dominan -> Sambaran Petir/Flashover. Ini mencegah evidence PANEN RISOL terlihat tidak berpengaruh saat kasus berada di luar ambang empiris PANEN RISOL.
- Summary dan Machine Learning memakai fallback `two_ended_local_single_result` bila `single_ended_result` lokal belum pernah dihitung, sehingga evidence PANEN RISOL tetap aktif setelah user hanya menghitung DE.
- Bila skor kandidat belum decisive, Summary memakai label eksplisit `Belum pasti: <kandidat terkuat>` alih-alih label generik agar user melihat objek/kandidat penyebab yang sedang bersaing.
- Guardrail: rule PANEN RISOL adalah bukti pendukung, bukan penyebab final otomatis. Penyebab final tetap perlu data eksternal/validasi lapangan.
