# Session 8 Juni 2026 - Sidebar, DE, Encoding, dan Streamlit Warnings

## Sidebar Upload-End Filter

- Filter GI/line tidak lagi berada di expander terpisah `Filter GI / Line`.
- Filter dipindah ke expander upload rekaman:
  - Local End: UPT, ULTG, Segment, GI, Bay / Line.
  - Remote End: UPT, ULTG, GI, Bay / Line.
- Segment hanya dipilih di Local End. Ini menjadi konteks line/tower, sementara UPT/ULTG Local dan Remote boleh berbeda untuk mengakomodir GI local dan GI remote yang berada di UPT/ULTG berbeda.
- Dropdown filter upload end hanya dirender jika `database_spreadsheet_url` tersedia dari credentials, secret/env, atau input Setup DB. Jika URL belum ada, panel upload hanya menampilkan uploader rekaman.
- Legacy key `sidebar_filter_upt` dan `sidebar_filter_ultg` tetap diisi dari pilihan Local End agar downstream lama tetap kompatibel.
- Case lama yang hanya punya `sidebar_filter_upt`/`sidebar_filter_ultg` otomatis men-seed `sidebar_filter_upt_local`/`sidebar_filter_ultg_local`.

## Sidebar Behavior

- `install_sidebar_accordion_rules()` di `app.py` menggantikan rule lama berbasis `st.components.v1.html`.
- Implementasi memakai `st.html(..., unsafe_allow_javascript=True)` agar tidak memunculkan warning deprecated `st.components.v1.html`.
- Fungsinya hanya accordion: saat satu expander sidebar dibuka, expander sidebar lain ditutup.
- Jangan kembalikan rule hide card upload setelah `.cfg + .dat` lengkap. Upload Local/Remote End harus tetap bisa dibuka agar user bisa melihat/mengubah filter GI/line atau mengganti rekaman.

## Refresh Button Encoding

- Tombol refresh/reload memakai escape Unicode `\u21bb`, bukan karakter refresh mentah, agar tidak berubah menjadi `?` atau mojibake.
- Contoh label yang dipakai:
  - `\u21bb Muat Ulang Daftar`
  - `\u21bb Refresh Nama File`
- Jangan pakai tombol ikon-only di landing page untuk reload case tersimpan; beri kata-kata agar user tidak bingung.

## Streamlit Widget Warnings

- Warning `widget created with a default value but also had its value set via Session State API` diselesaikan dengan guard `install_restored_widget_default_guard()` di `app_runtime.py`.
- Jangan mencampur `value=`/`index=`/`default=` dengan `key=` jika key widget dapat diisi dari restore/session_state.
- `FormSubmitter:` harus tetap masuk exclude/cleanup restore di `case_storage.py`; jangan set value submit button via session_state.

## Signal Assignment dan Cache

- Local dan Remote Signal Assignment memakai form Apply agar checkbox/kontrol channel tidak memicu rerun berat setiap perubahan kecil.
- Hasil assignment dicache via `get_cached_signal_assignment()` / `make_signal_assignment_cache_key()`.
- Cache waveform harus menyertakan flag invert polaritas agar plot langsung berubah saat polaritas dibalik.

## DE dan Summary Cache

- Setelah kalkulasi DE, cache grafik Summary SE/DE harus dibuang atau version key dinaikkan supaya Summary mengambil hasil terbaru.
- `_sloc_key` Summary sudah menyertakan `summary_location_cache_version` dan dependency DE/SE penting.

## Tower Schedule Segment Hyphen

- Segment matching harus adaptif terhadap variasi tanda hubung, misalnya `GNTUA-SBHAN` dan `GNTUA - SBHAN`.
- Query/filter Tower Schedule harus mempertimbangkan alias exact, collapsed hyphen, dan spaced hyphen agar spreadsheet dengan salah satu format tetap cocok.
