## Sidebar Behavior

- `install_sidebar_accordion_rules()` di `app.py` menggantikan rule lama berbasis `st.components.v1.html`.
- Implementasi memakai `st.html(..., unsafe_allow_javascript=True)` agar tidak memunculkan warning deprecated `st.components.v1.html`.
- Fungsinya hanya accordion: saat satu expander sidebar dibuka, expander sidebar lain ditutup.
- Guardrail implementasi accordion:
  - Pakai JavaScript minimal berbasis click listener pada sidebar.
  - Saat user membuka expander yang masih tertutup, tutup expander lain dengan `otherSummary.click()` agar state visual Streamlit (arah panah) dan konten tetap sinkron.
  - Jangan pakai native `<details name="...">`; hasilnya bisa membuat konten hide/show tidak selaras dengan arah panah card Streamlit.
  - Jangan pakai `removeAttribute("open")` atau `det.open = false`; panah card bisa salah walau konten tertutup.
  - Jangan pakai `MutationObserver` untuk enforce open/close; pernah membuat aplikasi freeze/crash saat card `Credentials` berisi file uploader lalu user membuka card lain.
- Jangan kembalikan rule hide card upload setelah `.cfg + .dat` lengkap. Upload Local/Remote End harus tetap bisa dibuka agar user bisa melihat/mengubah filter GI/line atau mengganti rekaman.

## Refresh Button Encoding

- Tombol refresh/reload memakai escape Unicode `\u21bb`, bukan karakter refresh mentah, agar tidak berubah menjadi `?` atau mojibake.
- Contoh label yang dipakai:
  - `\u21bb Muat Ulang Daftar`
  - `\u21bb Refresh Nama File`
- Jangan pakai tombol ikon-only di landing page untuk reload case tersimpan; beri kata-kata agar user tidak bingung.

## R-X Locus Zone Source

- Default sumber zona proteksi R-X Locus adalah `line_data`, bukan `distance_settings`, bila sheet tersebut tersedia.
- `line_data` dipilih karena punya kolom satuan eksplisit: `Z1/Z2/Z3 Sec`, `R1/R2/R3 P/G Sec`, `Z1/Z2/Z3 Prim`, `R1/R2/R3 P/G Prim`.
- Saat base `primary`, parser harus memakai kolom `Prim`; saat base `secondary`, parser harus memakai kolom `Sec` lalu dikonversi ke primary memakai CT/VT Signal Assignment.
- `distance_settings` tetap fallback karena beberapa database lama hanya punya kolom `Z1/X1`, `Z* Res Ph`, `Z* Res Gnd` tanpa satuan eksplisit.
- Untuk restore case, R-X Locus harus memilih Bay/line dari sidebar juga. Struktur `line_data` baru memisahkan `Nama Line` dan `Nomor Line`; parser harus membaca `Nama Line` sebagai Bay/nama line dan `Nomor Line` sebagai nomor line. Format lama `Nama Line dan Nomor Line` tetap fallback.
